# LAYERS STRESS TESTER
C2 Style Stress Tester

# Description
A tool for conducting stress tests using commands within a C2 TUI-style terminal window.

# How it works
HTTP attacks rapidly send HTTP requests asynchronously via a proxy.
TCP attacks rapidly send requests using a connection-based method.
UDP attacks rapidly send UDP packets.
Minecraft attacks flood Minecraft servers with handshake requests.
